# Question rules for MCQ quizzes

1. Exactly four options, labelled a, b, c, d. Exactly one is correct.
2. The stem asks one thing. State it positively; avoid "which is NOT" unless the
   difficulty is hard.
3. Distractors must be plausible: real misconceptions, near-miss terms, or values
   from the same category. Never silly options.
4. Never use "all of the above" or "none of the above".
5. Keep options similar in length and grammar so the answer is not obvious.
6. Spread correct answers across a, b, c, d. No letter may be correct more than
   40 percent of the time.
7. Every question must be answerable from the source text. Do not add outside facts.
8. Code in a stem or option goes in backticks. Keep snippets under 5 lines.

## Difficulty guide

- easy: recall a definition or a fact.
- medium: apply a fact to a short example, or compare two concepts.
- hard: predict the output of a snippet, or spot the subtle bug.
